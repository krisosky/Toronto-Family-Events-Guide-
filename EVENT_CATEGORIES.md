# EVENT_CATEGORIES.md

Version: 1.0

Last Updated: 2026-10-29

Owner: Family Events Guide

## Purpose

This document defines the official event categories used by Family Events Guide.

Every event must be assigned at least one category.

Multiple categories may be assigned when appropriate.

Only categories listed in this document may be assigned unless this document is formally updated.

---

# CORE CATEGORIES

## FREE EVENTS

Definition:

Events that have no admission fee or participation cost.

Examples:

* free library programs
* free festivals
* free museum days
* community celebrations

---

# CATEGORY ASSIGNMENT RULES

Every event must have:

* one Primary Category

Optional:

* up to four Secondary Categories

Maximum:

* five total categories per event

---

# MULTI-CATEGORY RULE

Events may belong to multiple categories when appropriate.

Example:

Free Family Science Festival

Categories:

* Free Events
* Festivals & Fairs
* STEM & Education
* Community Events

---

# CATEGORY LIMIT

Assign no more than five categories to any event.

Use the most relevant categories first.

Avoid category inflation.

---

# REVIEW RULE

If no category clearly fits:

Assign:

Needs Review

and flag for human review.

---

# GOVERNING RULE

EVENT_CATEGORIES.md is the official source of truth for all event category assignments.

All website pages, search filters, event records, organizer submissions, OpenClaw skills, newsletters and SEO pages must use these categories unless formally updated.
