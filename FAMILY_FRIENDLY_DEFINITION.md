# FAMILY_FRIENDLY_DEFINITION.md

Version: 1.0

Last Updated: 2026-10-28

Owner: Family Events Guide

## Purpose

This document defines what qualifies as a family-friendly event for Family Events Guide.

All future event collection, review, categorization, verification, newsletter selection, website publication, organizer approval and OpenClaw automation must follow these standards.

Family safety, legitimacy and trust take priority over event volume.

---

# CORE DEFINITION

A family-friendly event is an activity, experience, gathering, attraction, program, class, camp, festival, performance, workshop or community event that is appropriate for children, families, parents, caregivers or multiple generations.

The event must be safe, publicly identifiable and provide one or more of the following:

* education
* recreation
* enrichment
* entertainment
* wellness
* community connection
* cultural engagement
* family bonding opportunities

---

# FAMILY EVENTS GUIDE VALUES

Family Events Guide seeks to promote events that support:

* Safety
* Family Connection
* Community Engagement
* Education
* Recreation
* Accessibility
* Inclusion
* Cultural Awareness
* Positive Childhood Experiences

These values should guide event approval decisions when situations are unclear.

---

# REQUIRED CRITERIA

To qualify for publication, an event should have:

* a clearly identifiable organizer
* a clearly identifiable venue or location
* a clearly identifiable date
* a clearly identifiable time
* publicly available information
* age-appropriate content
* a verifiable source of information

Preferred but not always required:

* organizer website
* organizer email
* organizer phone number
* registration page
* social media presence

---

# VERIFICATION REQUIREMENTS

At least one of the following should be present whenever possible:

* official website
* organizer website
* municipal website
* library website
* museum website
* school board website
* community organization website
* registration page
* verified social media account
* direct organizer confirmation

Events lacking reasonable verification should be flagged for review.

# ACCESSIBILITY PRINCIPLE

Family Events Guide encourages the inclusion of accessible programming whenever possible.

Accessibility may include:

* wheelchair accessibility
* accessible washrooms
* sensory-friendly accommodations
* support-person accommodations
* inclusive programming

Accessibility is encouraged but is not required for event approval unless otherwise mandated by law.

# EVENTS THAT DO NOT QUALIFY

The following event types are not eligible for publication:

## Adult-Oriented Events

* adult entertainment
* sexually explicit events
* adult-only parties
* age-restricted nightlife

## Gambling Activities

* casinos
* gambling events
* betting-focused events

## Drug-Related Activities

* cannabis-focused events
* recreational drug events
* drug promotion events

## Unsafe Events

* events with significant safety concerns
* events presenting unreasonable risk to participants

## Unverifiable Events

* unknown organizers
* unknown locations
* unknown event dates
* events lacking verifiable information
* events appearing fraudulent or misleading

## Illegal Activities

* activities that violate applicable laws
* activities promoting criminal behaviour

---

# SAFETY STANDARDS

Family safety takes priority over event volume.

When evaluating events:

* public venues are preferred
* established organizations are preferred
* verifiable organizers are preferred
* child safety concerns should be taken seriously

The following should automatically trigger review:

* private residence events
* unverified organizers
* missing contact information
* conflicting event information
* unclear age suitability
* reports from users
* suspicious or misleading information

---

# APPROVAL STATUS

All reviewed events should receive one of the following statuses:

## Approved

Event meets Family Events Guide standards.

## Needs Review

Event requires additional verification or human review before publication.

## Rejected

Event does not meet Family Events Guide standards and should not be published.

---

# FINAL DECISION RULE

When safety, legitimacy, authenticity, organizer identity or age suitability cannot be determined with reasonable confidence:

Status = Needs Review

Do not automatically approve the event.

Family safety and trust always take priority over publishing additional events.
